# Painter Reference 1.2.0+45

Released 2026-08-16.

## Bugs fixed

- Fixed camera uploads failing with a 500 error (`unsupported Unicode escape sequence`). EXIF fields like camera make/model/lens are fixed-length and null-padded per the TIFF spec, so a real camera's metadata could carry an embedded null byte through to the `photo_metadata` sent to the server — and Postgres's `jsonb` type hard-rejects an embedded null character, which failed the entire upload (the image and thumbnail had already reached storage, but the database row never got created). EXIF strings are now sanitized before they're sent anywhere.
- The home screen's Camera button had no error handling around the camera picker call at all, and the app has no global crash handler — so if the camera intent failed for any reason, it would fail completely silently with no message. It's now wrapped the same way as the other camera/gallery entry points in the app, with a visible error message on failure.

## Deployment

- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
