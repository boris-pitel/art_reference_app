# Painter Reference 1.2.0+93

Release prepared 2026-09-08.

## Features and improvements

- Browse the remembered user's cached library without a network connection.
- Track connectivity changes while the app is open and show offline status.
- Add or capture new images offline in Inbox and reference categories. Originals are saved persistently on the device, with pending previews and retry controls.
- Upload queued images when connectivity returns and the owning user is signed in. Preserve pending images across app restarts.
- Keep existing images and categories read-only offline to prevent conflicting edits from multiple devices.
- Separate local image caches and queued uploads by user; clear them when that account is deleted.

## Deployment targets

- iPhone: existing TestFlight distribution.
- Android: existing Firebase App Distribution testing channel.
- Windows: local Painter Reference release application.
