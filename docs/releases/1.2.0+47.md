# Painter Reference 1.2.0+47

Released 2026-08-15.

## Features and improvements

- The Image Details screen's "Photo details" section (original filename, capture date, camera/lens/aperture/shutter/ISO/focal length) has been merged into the "Technical" panel instead of being a separate section — one collapsible panel with all the technical/metadata info together.
- Image pixel dimensions (width × height) are now captured at upload time and shown in the Technical panel. Both platforms already decode the full image to build the thumbnail, so this comes at no extra cost. Existing images uploaded before this release won't have dimensions recorded (the field was never populated before), but any new upload will.

## Deployment

- Supabase Edge Functions (`finalize-image-upload`, `get-image-metadata`) — no DB migration needed, `width`/`height` columns already existed on `image_assets` but were never populated.
- Android release installed on the connected phone. Skipped the full test suite at the user's request for a fast turnaround, same as the previous diagnostic build.
