# Painter Reference 1.2.0+88

Released 2026-08-30.

## Bugs fixed

- Resetting a forgotten password now works. The app emails you a six-digit
  code, which you type in wherever you happen to be. Previously it sent a link
  that could only be opened on the device that asked for it — so a reset begun
  on Windows and opened on a phone quietly did nothing, and dropped you on the
  home screen looking as though it had worked.

## Worth knowing

- Codes last an hour, and you can send yourself another from the same screen.
- Entering the code signs you in as well as changing your password.

## Platforms

- Web, Windows, Android and iOS.
