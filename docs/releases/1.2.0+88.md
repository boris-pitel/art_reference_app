# Painter Reference 1.2.0+88

Released 2026-08-30.

## Bugs fixed

- Resetting a forgotten password now works. You are sent a six-digit code by
  email and type it into the app, on whichever device you happen to be
  holding.

  It used to send a link, and a link had to be opened on the same device that
  asked for it. Asking on the computer and opening on the phone did nothing at
  all: no message, no error, just the home screen — which looked as though it
  had worked when it had not.

## Platforms

- Web, Windows, Android and iOS.
