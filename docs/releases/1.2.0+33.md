# Painter Reference 1.2.0+33

Released 2026-08-13.

## Features and improvements

- Added user-to-user messaging. Use "Send to friend" on any reference image to send it (with an optional note) to another user by username.
- Conversations are threaded: messages with the same person land in one ongoing thread, visible from the new Messages icon on the home screen.
- Profiles are discoverable by username by default; a new "Privacy and blocking" setting lets you hide from search or block a specific user. Blocking stops that person's messages from reaching you.

## Bugs fixed

- Fixed an image action sheet that could overflow off the bottom of the screen on shorter phones.

## Deployment

- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
