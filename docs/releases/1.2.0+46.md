# Painter Reference 1.2.0+46

Released 2026-08-16.

## Notes

Diagnostic-only build, Android only, skipped the normal test suite at the user's request to get a fast turnaround for investigating why EXIF/Photo details still doesn't show up for a specific photo despite the 1.2.0+44/1.2.0+45 fixes.

Every previously-silent failure point in the EXIF extraction pipeline (`HeifExifReader.findExifPayload`, `PhotoMetadataService.extract`/`extractFromRawExif`) now logs (via `debugPrint`, same mechanism already visible in this app's logs) exactly where and why extraction stopped, instead of just returning null with no trace. `image_asset_service.dart` also logs whether a given upload was detected as HEIC and what the metadata extraction ultimately produced. No behavior changes — same fallback-to-null-on-any-failure design as before, just now observable.

## Deployment

- Android release installed on the connected phone.
