# Painter Reference 1.2.0+84

Released 2026-08-28.

## Features and improvements

- Administrators can send a password reset to any user straight from the user
  list, instead of going to the database or setting one by hand.
- Changing your password now asks for your current one first. Without it,
  anyone holding your unlocked phone could take the account from you.

## Platforms

- Web, Windows, Android and iOS.
