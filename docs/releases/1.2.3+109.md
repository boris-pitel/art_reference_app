# Windows admin Unison shopping cart — 1.2.3+109

On branch codex/admin-unison-matching. Adds a shopping cart action to matching results and a cart button on the home screen. Selecting a match adds one full-size stick; repeated selections increase quantity. Quantities can be changed or removed. Cart is saved locally by Supabase account id and survives reopening; no cloud cart table or cross-device sync is included.

Shop at Dakota opens an embedded Windows WebView2 browser at the observed Unison Individual product page. An explicit Add selected sticks button checks the exact retailer SKU against public product rows, rejects missing/unavailable items before submitting anything, fills quantities, and clicks Dakota's Buy All control once. No credentials or payment data are read by app code. Prices, checkout, shipping, order placement and payment stay under user control in Dakota's browser. View Dakota cart opens /Checkout/Cart. Local list is retained. Repeated transfers may add duplicates; confirmation explains this and automatic retry is prevented after an ambiguous submission.

Microsoft Edge WebView2 Runtime is required. If unavailable, the page reports the requirement; Copy list provides a manual fallback. The embedded Dakota session is separate from the user's Chrome session. No backend migration is required.

Validation: eight tests pass (cart duplicate merging, persistence/account isolation, quantity/SKU validation, script guards, platform restriction, color-distance references, version consistency). Static analysis passed. Dakota public page structure inspected; user confirmed Buy All works. Live cart submission from the compiled Windows app and checkout have not been tested; no test order or payment was made.

The generated cart JavaScript also passes an executable Node DOM-fixture test for exact quantities and single submission (nine tests total). Tests require Node.js for this adapter check. WebView Windows 0.4.0 requires the targeted MSVC experimental-coroutine compatibility definition in windows/CMakeLists.txt on Visual Studio 2026.
