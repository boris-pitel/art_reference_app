# Windows build 114

Open the Unison shopping cart and choose Add pastels to browse all catalogue swatches. Search code, printed code, retailer SKU, official name or approximate name. Search words are combined with AND, case-insensitively. No matches produces an empty result list; clearing the search restores the catalogue. Codes sort naturally (A2 before A10). Rows show swatches, availability including Dakota's expected date, live unit prices, and Add or In cart quantity controls. The cart icon keeps its total stick count.

Shopping cart rows now show unit prices, line estimates and availability dates. An estimated total is shown before tax/shipping; missing prices are identified as unpriced quantities with only a known-price subtotal, never silently counted as free. Matching suggestions also show prices and expected dates. Prices are parsed as USD cents from Dakota's public product rows, including a sale price and previous price when supplied. No price is hard-coded or stored as a checkout quote. All views preserve the five-minute automatic stock refresh and Unknown state for failed checks.

Validation: 16 focused tests passed, covering search/no-result UI, add/quantity controls, account-scoped cart persistence/counts, USD and sale pricing, partial totals, expected-date parsing, duplicate DOM rows, cart transfer, colour matching, platform gating and app version. Analysis of nine changed components passed. The updated reader was run read-only on Dakota's live page: 380 rows, each currently $5.95, with Grey14 expected approx 9/18 preserved verbatim.

Windows/admin only, on codex/admin-unison-matching. No backend, web or phone deployment.
