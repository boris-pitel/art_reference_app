# Painter Reference 1.2.0+41

Released 2026-08-15.

## Features and improvements

- None in this release.

## Bugs fixed

- Impersonating a second user in the same session (after already impersonating one, or after returning to your own account) could show the "Impersonating {email}" banner correctly while the category grid still showed the previous identity's data. The home screen only loaded its categories once, on first launch, and never re-fetched when the signed-in identity changed underneath it since impersonation reuses the existing screen instead of recreating it. It now refreshes automatically every time impersonation starts or ends, so a manual refresh is no longer needed.

## Deployment

- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
