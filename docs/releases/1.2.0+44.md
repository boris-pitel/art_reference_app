# Painter Reference 1.2.0+44

Released 2026-08-16.

## Features and improvements

- Photo details (aperture, shutter speed, ISO, camera, timestamp, etc.) now work for photos uploaded from an iPhone. HEIC — the default iPhone capture format — stores EXIF as a distinct item inside its container rather than inline the way JPEG does, and the HEIC-to-JPEG conversion this app already does for compatibility only preserves orientation, discarding the rest. EXIF is now read directly from the original HEIC bytes before that conversion happens.
- Maintenance screen's Activity tab entries are now selectable, so their fields can be copied out.

## Bugs fixed

- None in this release.

## Deployment

- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
