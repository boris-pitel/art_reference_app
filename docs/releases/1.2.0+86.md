# Painter Reference 1.2.0+86

Released 2026-08-29.

## Bugs fixed

- A picture that could not be displayed showed nothing at all — a blank screen
  with no explanation. It now says it could not be loaded, and the failure is
  recorded so it can be looked into.
- In the AI editor, the original was shown in the same place as the result
  while an edit was running and after one failed, with no way to tell them
  apart. The picture is now labelled, and progress and errors appear on the
  image rather than below the prompt where they could be scrolled out of sight.
- Move Reference and Save to a category were laid out too wide for a phone, so
  the category list was cut off at the edges.

## Features and improvements

- After an AI edit, hold the compare button to see the original in the same
  frame. Letting go returns to the result.
- Images are kept on the device until the space is needed, rather than being
  thrown away after thirty days.

## Platforms

- Web, Windows, Android and iOS.
