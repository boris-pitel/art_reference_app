# Painter Reference 1.2.0+90

Released 2026-08-30.

- Password reset now accepts the complete code sent by email instead of
  stopping after six digits.
- Sending another password-reset code now works from the code-entry screen.
- Verifying a recovery code no longer opens a second password dialog.
