# Painter Reference 1.2.0+92

Released 2026-08-31.

## Improvements

- Password recovery now uses a larger, staged dialog. Password fields remain
  disabled until the complete eight-digit code is verified, then focus moves
  directly to the new-password field.
- Custom crop proportions now keep a five-item most-recently-used list in
  addition to explicitly saved ratios.

## Bugs fixed

- Aspect-ratio crops are calculated in image pixels, so choosing 1:1 on a 3:4
  image produces a centered square instead of allowing the whole portrait.
- Pending crop, rotation, monochrome and grid adjustments are passed into AI
  Edit rather than silently editing the original image.
- A newly generated AI image can be edited immediately from its seeded cache.
  Rejected signed URLs are refreshed and retried once.
- The version displayed inside the app now agrees with the packaged build
  number, with an automated regression test preventing another mismatch.

## Deployment

- Android testing release through Firebase App Distribution.
- iOS testing release through TestFlight.
- Windows Painter Reference release build.
