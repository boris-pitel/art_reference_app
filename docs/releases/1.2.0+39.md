# Painter Reference 1.2.0+39

Released 2026-08-14.

## Features and improvements

- Collapsed the image upload flow from 4 sequential network calls to 3: the original and its thumbnail are now uploaded to Storage together (concurrently) using signed URLs handed out by `prepare-image-upload`, and `finalize-image-upload` verifies and records both in one step. The separate `upload-thumbnail` Edge Function has been retired. This also closes a gap where a crash between finalize and the old separate thumbnail call could permanently leave an image without a thumbnail.
- Thumbnail generation now starts as soon as the image is normalized, overlapping with hash calculation and the `prepare-image-upload` network call instead of running after it.

## Bugs fixed

- None in this release.

## Deployment

- Supabase Edge Functions (`prepare-image-upload`, `finalize-image-upload`) redeployed; `upload-thumbnail` removed from the project.
- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
