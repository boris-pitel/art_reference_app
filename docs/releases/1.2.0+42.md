# Painter Reference 1.2.0+42

Released 2026-08-15.

## Features and improvements

- Image Details now has a collapsible "Photo details" section showing original filename, when the photo was taken, camera make/model, lens, aperture, shutter speed, ISO, and focal length — extracted automatically from the image's EXIF data at upload time. The section only appears when at least one of these is actually available.
- Uploads now capture the original filename (from the file picker or shared image) alongside the EXIF-derived fields.

## Bugs fixed

- None in this release.

## Deployment

- Supabase migration (new `original_filename`, `capture_timestamp`, `photo_metadata` columns on `image_assets`).
- Supabase Edge Functions (`finalize-image-upload`, `get-image-metadata`) redeployed.
- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
