# Windows build 111

The Windows admin Unison tool now shows total stick quantity below its cart icon on the home and colour matching screens. Counts follow additions, quantity changes and removals, and remain scoped to the signed-in account.

Suggested sticks show Dakota availability: In stock, Out of stock, Discontinued or Unknown. The app reads Dakota's public product rows using its embedded WebView2 browser, including explicit discontinued text. Missing rows, blocked pages and failed checks remain Unknown. The check runs when the matching screen opens, expires after five minutes, and can be refreshed manually. The expandable Dakota stock page allows the user to inspect the source or handle a browser prompt themselves. The reader does not change Dakota's cart.

Validation: 13 focused tests passed, including live cart count/account changes, availability classification, responsive duplicate handling, cart transfer and colour matching. Flutter analysis of the modified matching/cart/stock components passed. The stock reader was also run read-only against Dakota's live page: 380 unique product rows; BE14 purchasable, Grey14 and Grey17 Notify Me. No currently displayed Unison row was labelled discontinued; that explicit-text case is covered by a fixture test.

Windows only; no phone, web or database deployment.
