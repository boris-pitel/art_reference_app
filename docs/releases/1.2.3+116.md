# iPhone admin Unison release

Enables Unison matching, catalogue search and the shopping cart for administrators on native iOS as explicitly requested. Windows access is retained; Android, web and other platforms remain excluded. The same app_metadata.is_admin and account checks apply at each entry point and screen.

Dakota stock/price reads and cart transfer use WKWebView through webview_flutter on iPhone and WebView2 on Windows. Both reuse the existing public DOM readers and transfer preflight/duplicate guards. Checkout and payment remain under the user's control. Cart quantities stay local to the device/account. Cart quantity controls appear below item details to fit a phone screen.

Validation: analysis of seven modified components passed; all 16 focused Unison tests passed, including iOS/Windows platform access, Android exclusion, a 375px-wide catalogue, search/no-results, cart persistence/counts, stock/price parsing and transfer guards. Native iOS compilation and publishing run on Codemagic using the existing Default Workflow. No Windows, Android or web deployment requested.
