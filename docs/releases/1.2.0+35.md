# Painter Reference 1.2.0+35

Released 2026-08-13.

## Features and improvements

- Added "Move..." to the long-press/right-click menu on individual images in a category, so a photo can be moved to a different category without opening its details first.
- Maintenance screen: the "Login name" field in a user's details is now editable — set or clear it directly, no need to switch to the separate admin console.
- Admin console: the Users table's Actions column (including the recently added "Set login name" button) was rendering off the right edge of the window on shorter timestamps; dates are now shown to the minute instead of the microsecond, and column spacing was tightened, so the actions are visible without scrolling.

## Bugs fixed

- None beyond the admin console layout issue above.

## Deployment

- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
- Windows admin console rebuilt locally.
