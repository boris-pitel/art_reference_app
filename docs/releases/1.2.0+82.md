# Painter Reference 1.2.0+82

Released 2026-08-28.

## Changes

- Signing in with Google or Apple has been withdrawn. Sign in with your email
  address and password as before — every existing account already does, so
  nothing is lost.

## Why

Apple would not authorise the app for Sign in with Apple, by any route and
with no explanation. Their rules only require it from an app that offers
another third-party sign-in, so removing both leaves the app compliant rather
than blocked. Both can return if Apple resolves it.

## Platforms

- Windows and iOS. Web and Android remain on 1.2.0+80.
