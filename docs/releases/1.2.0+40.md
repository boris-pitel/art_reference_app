# Painter Reference 1.2.0+40

Released 2026-08-15.

## Features and improvements

- Maintenance screen: added an "Impersonate" action to the user details dialog. It signs the admin in as the selected user (via a short-lived, single-use token — no passwords involved) for troubleshooting, and shows a persistent "Impersonating {email} — Return to my account" banner across every screen until the admin switches back. Every impersonation is logged to the activity log.
- No new binaries or separate admin tooling required — this works entirely from within the main app for any account already flagged as an administrator.

## Bugs fixed

- None in this release.
