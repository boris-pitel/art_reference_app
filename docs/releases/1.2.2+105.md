# Painter Reference 1.2.2+105

Prepared 7 October 2026. Not deployed.

- Upload PDF, TXT, RTF, DOCX, and DOC documents (up to 25 MB) into categories alongside images, without a new filter.
- Show file-type badges, document titles, and first-page PDF thumbnails when rendering is available. Documents sort with images by the date added.
- Read PDF and text files in the app. RTF previews support basic text formatting, headings, and lists; complex layout is preserved in the original file. Word documents open in the device's default application or download in the browser.
- Save the original file, edit titles/notes/keywords/favorites, and find documents through the existing reference search.
- Cache opened or uploaded files for offline access. Document uploads and metadata changes require an online session in this first cut.
- Store documents privately with account-scoped database and Storage policies. Deleting a category moves documents to Inbox. Account deletion removes document storage and local cached files.

Deployment prerequisites:

1. Apply `supabase/migrations/20261007000000_reference_documents.sql` with `npx supabase db push`. A dry run confirmed this is the only pending migration; it has not been applied.
2. Deploy `delete-my-account` with `npx supabase functions deploy delete-my-account --use-api` to include document storage cleanup.
3. Deploy the build 105 clients. Do not use the version-bumping release scripts without `-SkipVersionBump`.
