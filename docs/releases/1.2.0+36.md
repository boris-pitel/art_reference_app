# Painter Reference 1.2.0+36

Released 2026-08-13.

## Features and improvements

- The home screen's mail icon now shows an unread-message badge with a count, updated on load, refresh, and after returning from Messages.
- Long-pressing an image inside a chat message now offers "Save to a category" (adds it to your own library), "Share", and "Save to Photos" — same as the actions already available elsewhere in the app.
- Images saved from a message you received now remember who originally sent them. Image Details shows "Originally from [name]" when set, and search now matches by that name too, alongside title, notes, and keywords.

## Bugs fixed

- None in this release.

## Deployment

- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
