# Painter Reference 1.2.2+102

Prepared 6 October 2026.

- Fill the camera preview in landscape so the live image is easier to frame.
- Show the featured edited image on category cards and open it from the thumbnail, while keeping the original available to restore.
- Read existing GPS coordinates from imported photos and let users enter a place name for a reference image.
- With location permission, save a recent phone location with photos taken using the app's Camera button, including photos queued while offline. Photo capture still works without location access.

The privacy policy now describes the optional location data.
