# Temporary photo search from the Unison catalogue

Browse Unison pastels now has a photo search button alongside the text search. On iPhone, Search by camera opens the system rear camera; on Windows, Search by photo opens the existing photo chooser. The captured/selected bytes open the existing Unison matching view, where tapping points ranks the three nearest sticks with swatches, prices and availability and allows adding them to the shopping cart. Returning restores the catalogue and text search.

The photo is used in memory and is not uploaded or added to the reference library. Capture uses a maximum 2000px preview, consistent with the existing matching preview. Camera cancellation makes no changes; capture errors leave the button usable. Duplicate taps and callbacks after leaving the screen are guarded. Existing native iOS/Windows administrator and account checks remain in place.

Validation: photo flow widget checks cover captured bytes, cancellation, duplicate taps, permission errors and disposal; existing catalogue, matching and platform tests cover search and colour matching. Physical iPhone camera interaction requires device verification after TestFlight deployment.
