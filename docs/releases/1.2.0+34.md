# Painter Reference 1.2.0+34

Released 2026-08-13.

## Features and improvements

- Find-a-friend search now matches usernames as a regular expression instead of a plain substring, and returns at most 15 results.
- "Send to friend" is now available on sketches (Associated Image Details), not just top-level references.
- Chat messages now show a timestamp on every bubble and get a visible border/extra spacing when the same sender sends several images in a row, so consecutive sends read as clearly separate messages instead of blending together.
- Admin console: added a "Set login name" action per user, and fixed the user list/search to read the live login name instead of stale signup-time data.

## Bugs fixed

- None in this release beyond the chat-bubble separation issue above.

## Deployment

- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
- Windows admin console rebuilt locally.
