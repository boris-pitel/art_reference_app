# Painter Reference 1.2.0+15

Released 2026-08-08.

## Features and improvements

- Added a My Art built-in category for sketches marked as finished paintings.
- Moved My Art to the first category position and added its category artwork.
- Added the ability to move a photo reference between categories.
- Added Edit details to associated-image actions.
- Moved the reference image action menu directly onto the image.
- Made crop handles larger, more visible, and easier to drag.
- Moved the in-app How To guide into a readable Markdown file.
- Added version and build-number display in About, with automatic build-number increments for release builds.

## Bugs fixed

- Creating a sketch no longer opens the crop editor automatically.
- A newly created sketch now appears in Associated Images immediately.
- Duplicate sketch saves now use a fast database lookup and show a friendly message instead of a raw database error.
- The "The image already appears straight" message now dismisses automatically.
- Category loading is more resilient when an individual category count cannot be retrieved.
- My Art links use the parent reference image correctly.
- The legacy category name Icon is displayed as Icons.

## Deployment

- Supabase database migration and Edge Functions deployed.
- Web application deployed to Firebase Hosting.
- Android release installed on the connected phone.
- Windows release built.
