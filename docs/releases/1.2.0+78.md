# Painter Reference 1.2.0+78

Released 2026-08-27.

## Features and improvements

- Categories now refresh themselves when you come back to the app after
  being away, so the pictures are ready rather than stale.

## Bugs fixed

- Fixed some thumbnails showing "unable to load" when a category was opened
  after the app had been left alone for an hour or more. The links the screen
  was holding had quietly expired; it now fetches new ones, and recovers on
  its own if a picture still fails.
- A thumbnail that cannot be loaded is now recorded, so this kind of fault
  can be seen rather than guessed at.
