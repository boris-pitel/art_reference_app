# Painter Reference 1.2.0+87

Released 2026-08-29.

## Features and improvements

- Compare a sketch with the reference it came from. Open a sketch's menu and
  choose "Compare with the reference". Fade between the two to check your
  proportions, put them side by side to choose between versions, or hold to
  swap one for the other.
- Arrows on the image move to the next and previous reference, with your
  position shown. Swiping still works; now there is something to see, and it
  works on Windows and the web, where there is no swipe at all.

## Bugs fixed

- Opening a sketch to edit it left you unable to move to the next one.
- Long category names were cut off in the move and save lists.
- On an Android phone set to dark mode, the app opened on a black screen for a
  moment before showing itself.

## Platforms

- Web, Windows, Android and iOS.
