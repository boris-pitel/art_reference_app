# Painter Reference 1.2.0+43

Released 2026-08-15.

## Features and improvements

- Image Details: new collapsible "Technical" section above Reference details, collapsed by default, showing image ID, date added, image hash, and storage paths (values are selectable for copying).
- Maintenance screen's Activity tab now shows how long each operation took, and shows the stored error message for any failed entry.

## Bugs fixed

- Fixed a bug (introduced in 1.2.0+42's Photo details feature) where uploading directly from the camera could fail. EXIF extraction was decoding the full-resolution photo a second time (on top of the decode thumbnail generation already does), which is much more expensive for a full-size camera photo than for a typical gallery image. Metadata extraction now reads from the already-generated thumbnail instead — package:image carries EXIF through a resize/re-encode, so the same data comes out, without paying for a second full-resolution decode.

## Deployment

- Supabase Edge Functions (`admin-maintenance`, `get-image-metadata`) redeployed.
- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference release build.
