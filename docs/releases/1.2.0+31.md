# Painter Reference 1.2.0+31

Released 2026-08-12.

## Features and improvements

- Added optional, unique login names for newly registered users and exposed login names in maintenance user details.
- Added a compact aspect-ratio selector with common photo, screen, ISO A0-A6, B5, and US paper formats in portrait and landscape orientations.
- Added persistent custom aspect ratios, with up to ten saved ratios that can be selected or removed.
- Added immediate progress feedback when saving an edited sketch.

## Bugs fixed

- Fixed logout being blocked by activity logging or network/DNS failures and moved Sign Out near the top of the account menu.
- Fixed the categories screen refreshing twice when returning Home.
- Fixed the custom aspect-ratio controls taking excessive space in the editor.

## Deployment

- Supabase database migrations and Edge Functions.
- Firebase web application.
- Android release installed on the connected phone.
- Windows Painter Reference and administration console release builds.
