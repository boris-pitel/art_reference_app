# How to Use Painter Reference

## Create an account
1. Select Create Account.
2. Enter your email address and choose a password.
3. Confirm your email if requested, then sign in.

## Manage categories
Tap Add Category to create a custom category. Use its three-dot menu to rename it, change its cover image, or delete it. Built-in categories cannot be renamed or deleted. My Art is the first built-in category and shows sketches marked as finished paintings.

## Add and organize a reference
1. Open the category where the reference should appear.
2. Tap Add Photo Reference and choose Gallery or Camera.
3. Open the reference details to add a title, notes, author, favorite status, and searchable keywords.
4. Use the three-dot menu directly on the image to move a reference to another category.

## Create and edit a sketch
1. Open a photo reference and tap the image to open the Image window.
2. Choose Edit sketch to crop, rotate, straighten, or change proportions. The large white circles at the crop corners are drag handles.
3. Tap Done, then Save as sketch. You return to the reference details and the new sketch appears under Associated Images.
4. To save an unedited copy, choose Save as sketch without opening the editor.

## Use associated images and My Art
Tap an associated image to open it. Its three-dot menu provides Open, Edit details, Share, Save to Photos, and Delete. In the sketch details, mark Finished painting to include it in My Art. A finished painting can be linked to only one photo reference.

## Refresh and troubleshoot
Use refresh if an upload or category cover does not appear. If you try to save the same sketch again, Painter Reference tells you it is already attached and does not upload another copy.
